      ↓

   • Analysis: Results processing and leaderboard generation
   • Tournament: Fair bracket generation with verification

GAME SYSTEM DETAILS
================================================================================

22 ROLES:
   Townsfolk (13): Laundress, Librarian, Investigator, Chef, Empath,
                   Fortuneteller, Undertaker, Monk, Raven, Virgin,
                   Slayer, Soldier, Mayor
   
   Outsiders (4): Butler, Drunk, Hermit, Saint
   
   Minions (4): Poisoner, Spy, Scarlet Woman, Baron
   
   Demon (1): Demon

GAME PHASES:
   • Night: Information roles gather data, demon kills, minions coordinate
   • Day: Public discussion, nomination, voting, execution

WIN CONDITIONS:
   • demon_killed: Demon dies (good wins)
   • two_alive: 2+ players with demon alive (evil wins)
   • saint_executed: Saint executed (evil wins)
   • mayor_win: Mayor alive with 3 players, no execution (good wins)

INFORMATION SYSTEM:
   • Private info per role (only visible to that player)
   • Public chat (all players see)
   • Evil chat (demon/minions only)
   • Poisoned players (can't receive new info)
   • Registration uncertainty (Spy/Hermit)
   • Truth/False decisions (Storyteller LLM)

================================================================================
TOURNAMENT SYSTEM DETAILS
================================================================================

FAIR ROTATION ALGORITHM:
   • 12 models play in fair Latin square arrangement
   • Each model plays each of 12 seats exactly once
   • Across 12 games per board group
   • Eliminates positional bias
   • Perfect reproducibility with seeding

STRUCTURE:
   • 5 board groups (professionally designed)
   • 12 games per group
   • 60 total games
   • Balanced roles: 1 demon + 2 minions + 4 outsiders + 5 townsfolk

SEEDED PRNG:
   • Base seed: config.seed (default: 42)
   • Game seed: config.seed * 1000 + gameIndex
   • Enables perfect reproduction of any game

VERIFICATION:
   • Each model occupies each seat exactly once
   • Each game has 12 unique models
   • Role distribution maintained
   • Schedule validation passed

================================================================================
KEY DESIGN PATTERNS
================================================================================

1. SEEDED REPRODUCIBILITY
   • All randomness uses seeded PRNG (mulberry32)
   • Enables perfect reproduction of any game

2. MULTI-LAYER COST ESTIMATION
   • API cost → local table → token estimate
   • Tracks source for transparency

3. SESSION COMPRESSION
   • Summarizes previous days to prevent context overflow
   • Reduces token waste while maintaining information

4. INCREMENTAL CHAT UPDATES
   • Only sends new messages since last round
   • Cursor tracking to avoid duplication
   • 60-70% token consumption reduction

5. FAIR TOURNAMENT ROTATION
   • Latin square model rotation
   • Each model plays each seat exactly once
   • Eliminates positional bias

6. LLM REGISTRATION SYSTEM
   • Storyteller decides spy/hermit registration
   • Dynamic truthfulness of information
   • Creates information uncertainty

7. COMPREHENSIVE TRAJECTORY LOGGING
   • All player interactions recorded
   • Per-player JSONL files
   • Includes LLM reasoning chains

QUICK START COMMANDS
================================================================================

1. Install Dependencies:
   npm install

2. Set API Key:
   export OPENROUTER_API_KEY="your-api-key"

3. Run Quick Test (2 games):
   cd benchmark
   node run.js --board-group 1 --limit 2

4. Generate Leaderboard:
   node stats.js

5. View Leaderboard:
   cat ../results/leaderboard.json

6. Run Full Evaluation:
   node run.js --board-group 1
   node run.js --board-group 2
   # ... repeat for 3-5

7. Scan All Previous Runs:
   node stats.js --scan-all
